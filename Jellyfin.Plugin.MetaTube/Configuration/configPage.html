JavDB

JavDB 会话 cookie，用于访问需要登录的条目（FC2 等素人番号）。浏览器登录 JavDB 后按 F12 → Network，任选一个 javdb.com 请求，复制 Request Headers 里的整个 Cookie 值粘贴到这里（至少要包含 _jdb_session=...）。保存后自动推送到 MetaTube 服务端，无需重启。cookie 失效时刮削日志会提示「JavDB cookie 已失效」，届时重新复制一份即可。

场景路由

正常翻译使用的通道。
A 返回拒答文案，或接口返回内容审核 / 敏感词错误时，用 B 重试一次。留空不降级。
A 超时时用 C 重试一次。B 和 C 是两条独立链路；B/C 再失败会直接报错，不再继续降级。
每行一条，译文包含任意一条（忽略大小写）即切到 B。留空使用默认：Sorry, I can't respond to this question
AI翻译时一次性传输的最大文字个数，默认2000
同时发起的翻译请求数上限，默认5。改完无需重启即时生效；调大更快但可能触发翻译服务限流。
没有单独配置 Provider 超时时使用的全局超时，默认600秒(10分钟)。改完无需重启。
需先打开上面的"是否要获取评论"。关闭时，定时任务只刷新在详情页点过"拉取评论"按钮的番号；打开时对所有番号都抓取评论（慢且耗翻译额度）。
打开后，媒体服务器"刷新元数据"会携带 update=true，让服务端重新抓取源站（lazy=false），而不是直接返回缓存。

Merge Multi Versions

Auto merge multiple versions of the same video (same MetaTube id) after library scans. Also available as a scheduled task.
逗号分隔的媒体库名单，只有名单内的库参与合并。留空 = 全选（所有电影库）。
关闭（默认）：番号组内任意条目带多 CD part 时整组不合并。打开：允许合并带 CD part 的条目，但要求组内每个番号的 part 数量完全一致，否则跳过。
